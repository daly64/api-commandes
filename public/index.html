API commandes

API de prise de commande pour le salon de thé. Elle reçoit les commandes des serveurs, les transmet à la cuisine et au bar, et fournit le menu.

Généralités

  • Adresse de base : l'adresse de cette page, suivie de /api.
  • Format : JSON (Content-Type: application/json).
  • Authentification : les routes /api/commandes exigent l'en-tête X-Api-Key. Sans clé valide, la réponse est 401. Le menu est public.
  • Débit : 300 requêtes par minute et par adresse. Au-delà, 429.

Endpoints

MéthodeAdresseRôleClé requise

GET/api/commandesCommandes non payéesOui

PATCH/api/commandes/:id/statutChanger le statut d'une commandeOui

GET /api/menu

{
  "categories": [{ "id": "6", "nom": "cafes", "visible": true }],
  "produits": [{ "id": "14", "nom": "Express", "prix": 2, "categorieId": "6", "visible": true }]
}

Le menu est mis en cache une minute. En cas d'erreur de l'API menu, la réponse est 502.

GET /api/commandes

Renvoie les commandes non payées, de la plus ancienne à la plus récente.

curl -H "X-Api-Key: VOTRE_CLE" https://VOTRE-ADRESSE/api/commandes
[
  {
    "id": 1,
    "table": 3,
    "lignes": [{ "produit": "Thé vert", "quantite": 2 }],
    "statut": "en_attente",
    "creeeLe": "2026-11-01T18:42:10.512Z"
  }
]

POST /api/commandes

Crée une commande pour une table.

curl -X POST -H "Content-Type: application/json" -H "X-Api-Key: VOTRE_CLE" \
  -d '{"table": 3, "lignes": [{"produit": "Thé vert", "quantite": 2}]}' \
  https://VOTRE-ADRESSE/api/commandes
ChampRègle
tableEntier entre 1 et 10
lignesDe 1 à 20 lignes
lignes[].produitTexte non vide, 100 caractères au maximum
lignes[].quantiteEntier entre 1 et 50

Réponse 201 : la commande créée, avec statut: "en_attente". Réponse 400 : { "erreurs": [...] } listant chaque règle non respectée.

PATCH /api/commandes/:id/statut

Modifie le statut de la commande :id.

curl -X PATCH -H "Content-Type: application/json" -H "X-Api-Key: VOTRE_CLE" \
  -d '{"statut": "en_preparation"}' \
  https://VOTRE-ADRESSE/api/commandes/1/statut

Réponse 200 : la commande modifiée. Réponse 400 si le statut est inconnu, 404 si la commande n'existe pas.

Statuts d'une commande

StatutSignification
en_attenteCommande reçue, pas encore lancée
en_preparationEn cours de préparation
pretePrête à être servie
servieApportée à la table
payeeEncaissée. Elle n'apparaît plus dans la liste
