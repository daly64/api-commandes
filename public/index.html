API commandes

API GraphQL de prise de commande pour le salon de thé, avec mises à jour en temps réel par WebSocket.

Clé d'accès

  • Le menu est public.
  • Tout ce qui concerne les commandes exige la clé du personnel : en HTTP, l'en-tête X-Api-Key ; en WebSocket, le paramètre de connexion apiKey.
  • Sans clé valide : erreur UNAUTHENTICATED en HTTP, connexion WebSocket fermée (code 4403).

Exemples

Créer une commande :

mutation {
  creerCommande(table: 3, lignes: [{ produit: "Express", quantite: 2 }]) {
    id statut lignes { produit quantite }
  }
}

Avec curl :

curl -X POST https://VOTRE-ADRESSE/graphql \
  -H "Content-Type: application/json" -H "X-Api-Key: VOTRE_CLE" \
  -d '{"query":"{ commandes { id table statut } }"}'

S'abonner en JavaScript (paquet graphql-ws) :

import { createClient } from 'graphql-ws';

const client = createClient({
  url: 'wss://VOTRE-ADRESSE/graphql',
  connectionParams: { apiKey: 'VOTRE_CLE' },
});

client.subscribe(
  { query: 'subscription { commandeModifiee { id table statut } }' },
  { next: (m) => console.log(m.data), error: console.error, complete() {} },
);
